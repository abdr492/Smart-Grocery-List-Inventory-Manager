A modern full-stack grocery inventory management system that helps users track pantry stock, manage grocery lists, monitor expiry dates, and receive low-stock alerts in real time.

Built with the MERN Stack, this project demonstrates complete full-stack development skills including authentication, REST APIs, database management, responsive UI design, and inventory logic. 

---

## 🚀 Project Overview

The **Smart Grocery List & Inventory Manager** is a full-stack web application designed to simplify grocery and pantry management for:

* Families
* Students
* Hostel residents
* Small grocery shops
* Cloud kitchens
* Cafés

Users can:

* Add grocery items
* Track quantities
* Set minimum stock levels
* Monitor expiry dates
* Generate shopping lists
* Receive low-stock alerts
* Manage inventory efficiently
